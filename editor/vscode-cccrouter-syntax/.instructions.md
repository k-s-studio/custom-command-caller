# cccrouter-syntax

VS Code extension，讓 `cccrouter.json` 裡指令模板中的 `$PARAM` 佔位符顯示成不同顏色，方便一眼看出哪裡是參數。

實作方式是 `extension.js` 註冊一個 semantic tokens provider，只對檔名為 `cccrouter.json` 的檔案生效，不影響一般 JSON 檔案。檔案本身仍維持 `json`/`jsonc` language id，所以 VS Code 內建的 JSON 語法檢查（錯誤底線、schema 驗證）不受影響。

執行 extension 本身只需要 VS Code 內建的 extension host（自帶 Node.js runtime），不需要額外安裝任何 runtime；只有「打包」這個開發步驟需要用到 `npx`/Node。

## 安裝（推薦）

直接用 ccc 內建指令安裝已打包好的版本：

```powershell
ccc highlighter install --vscode
```

這會把 repo 裡已打包的 `cccrouter-syntax-*.vsix` 透過 `code --install-extension` 正式安裝（VS Code 會像管理一般 extension 一樣管理它），裝完 reload window 即可生效。

## 修改語法定義後重新打包

如果你修改了 `package.json` 或 `extension.js`，在 repo 根目錄執行：

```powershell
Push-Location editor/vscode-cccrouter-syntax
npx --yes @vscode/vsce package
code --install-extension .\cccrouter-syntax-0.0.7.vsix
Pop-Location
```

這會直接覆蓋舊的 `.vsix` 並重新安裝，不需要改版號。

之後執行 `scripts/install.ps1` 重新安裝 ccc 時，會自動把資料夾裡的 `.vsix` 一併打包進 `~/.ccc`，讓 `ccc highlighter install --vscode` 用到新版本。

> 不要手動把這個資料夾複製或建立 symlink 到 VS Code 的 `extensions` 目錄——那不是 VS Code 認可的安裝流程，版本更新也不會被正確追蹤。一律透過 `.vsix` + `code --install-extension` 安裝。

## 自訂顏色

`extension.js` 會辨識指令模板字串裡的兩種佔位符，並各自回報成獨立的 semantic token type：

- `${VAR}`、`$VAR`（對應 `params` 設定的具名參數）→ `cccPlaceholder`
- `{n}`、`{n=default}`（CLI 傳入的位置參數，可帶預設值）→ `cccPositional`

extension 的 `configurationDefaults` 已內建預設顏色。若想要自訂，可以在使用者 `settings.json` 加上：

```json
"editor.semanticTokenColorCustomizations": {
    "rules": {
        "cccPlaceholder": { "foreground": "#f1d900", "fontStyle": "bold" },
        "cccPositional": { "foreground": "#6e4dff", "fontStyle": "bold" }
    }
}
```
