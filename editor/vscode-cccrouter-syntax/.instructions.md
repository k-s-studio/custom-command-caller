# cccrouter-syntax

VS Code 語法定義檔，讓 `cccrouter.json` 裡指令模板中的 `$PARAM` 佔位符顯示成不同顏色（`variable.parameter.placeholder.cccrouter` scope），方便一眼看出哪裡是參數。

只對檔名為 `cccrouter.json` 的檔案生效，不影響一般 JSON 檔案。

## 安裝（推薦）

直接用 ccc 內建指令安裝已打包好的版本：

```powershell
ccc highlighter install --vscode
```

這會把 repo 裡已打包的 `cccrouter-syntax-*.vsix` 透過 `code --install-extension` 正式安裝（VS Code 會像管理一般 extension 一樣管理它），裝完 reload window 即可生效。

## 修改語法定義後重新打包

如果你修改了 `package.json`、`language-configuration.json` 或 `syntaxes/cccrouter.tmLanguage.json`，在 repo 根目錄執行：

```powershell
Push-Location editor/vscode-cccrouter-syntax
npx --yes @vscode/vsce package
code --install-extension .\cccrouter-syntax-0.0.7.vsix
Pop-Location
```

這會直接覆蓋舊的 `.vsix` 並重新安裝，不需要改版號。

之後執行 `scripts/install.ps1` 重新安裝 ccc 時，會自動把資料夾裡的 `.vsix` 一併打包進 `~/.ccc`，讓 `ccc highlighter install --vscode` 用到新版本。

> 不要手動把這個資料夾複製或建立 symlink 到 VS Code 的 `extensions` 目錄——那不是 VS Code 認可的安裝流程，版本更新也不會被正確追蹤。一律透過 `.vsix` + `code --install-extension` 安裝。

## 自訂顏色

語法檔會辨識指令模板字串裡的四種佔位符，並各自給予獨立 scope：

- `${VAR}`、`$VAR`（對應 `params` 設定的具名參數）→ `variable.parameter.placeholder.cccrouter`
- `{n}`、`{n=default}`（CLI 傳入的位置參數，可帶預設值）→ `variable.parameter.positional.cccrouter`

另外 JSON 物件的鍵也有獨立 scope `support.type.property-name.json`，會跟一般字串值分開上色。

預設顏色取決於目前的 color theme 如何渲染這些 scope。若想要更醒目，可以在使用者 `settings.json` 加上：

```json
"editor.tokenColorCustomizations": {
    "textMateRules": [
        {
            "scope": "variable.parameter.placeholder.cccrouter",
            "settings": { "foreground": "#f1d900", "fontStyle": "bold" }
        },
        {
            "scope": "variable.parameter.positional.cccrouter",
            "settings": { "foreground": "#6e4dff", "fontStyle": "bold" }
        }
    ]
}
```
